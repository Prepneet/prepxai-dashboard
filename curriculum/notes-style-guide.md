# PrepX Ai Notes Standard

Every published note must be original PrepX Ai teaching content. Do not upload coaching PDFs, screenshots, copied textbook pages, or institution-watermarked material.

## Note types
- **Detailed notes:** concept-first explanation, worked reasoning, definitions, diagrams, common mistakes, and exam-focused checks.
- **Short revision:** one-screen / one-page recap, key facts, formulae, exceptions, and memory cues.
- **Formula sheet:** formula, symbol meanings, units, assumptions, and the conditions under which it applies.

## Required metadata
- Exact exam and current syllabus year
- Subject, official unit/chapter, and syllabus topic link
- Language: English, Hindi, or Hinglish
- Official syllabus source name and URL
- Reading time and content version
- Academic review before publication

## Visual design
- Use the PrepX Ai ruled-paper / handwritten visual style consistently.
- Use original diagrams and concept maps; label every important part.
- Use animations only when motion explains a concept (e.g. orbit, wave, projectile path).
- Keep diagrams readable on mobile and in print/PDF.
- Never use a decorative animation that makes the concept less accurate.

## Content quality checklist
1. Explain the idea in original language before giving a formula.
2. Define every symbol and state units.
3. State assumptions and limitations (e.g. idealisations).
4. Include at least one common misconception or exam trap.
5. Cross-check the topic against the current official exam-year syllabus.
6. Separate official syllabus content from supplementary foundation material.
7. Do not mark a topic or note as verified unless the official reference has been checked.
8. Exported PDFs must retain PrepX Ai branding, headings, diagrams, and readable typography.
